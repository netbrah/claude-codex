Terminal-native LLM agent for software engineering. Multi-model, multi-wire protocol. Single binary, zero runtime dependencies.

Install

bash

The installer downloads the XLI binary to ~/.local/bin/, bootstraps ~/.xli/config.toml, and adds to your PATH. Re-run anytime to update.

Requires VPN — you need NetApp VPN connected to reach Artifactory and the LLM Proxy.

Troubleshooting

"xli: command not found"

The installer adds ~/.local/bin to your shell profile. Open a new terminal or run:
export PATH="$HOME/.local/bin:$PATH"

 curl fails during install

Connect to VPN first. Verify Artifactory is reachable: curl -I https://generic.repo.eng.netapp.com

 SSL/TLS certificate errors

macOS: export SSL_CERT_FILE="/etc/ssl/cert.pem"
Linux: should work out of the box with system CA bundle.

 Uninstall

rm ~/.local/bin/xli && rm -rf ~/.xli
Then remove the export PATH line from your shell profile.
